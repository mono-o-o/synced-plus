How to Use

1. Load Audio: Click on the Open Audio button to load a track. Metadata input fields will automatically be filled if your audio file has them.

2. Load Lyrics / Add Lines: Click on the Import button to load a lyric file or paste from the clipboard.

3. Sync Lines / Words: Use the timestamp button inside a time field to set its value to the current playback time.

To sync words, click on the Expand button to see the word container. When a time has been set for a word, clicking on the word jumps audio playback to its time.

By default, line end timestamps create a new, empty line in the LRC file, a common practice in LRC creation. This can be changed in the settings.

4. Export: Click on the Export button to select your desired format and download it.

Import LRC / ELRC

Import a synced lyric file. Timestamps and metadata are automatically detected and mapped into the workspace.

Import TXT

Import a plaintext file. Separates every line as new lyric lines in the workspace.

Import SRT

Import an SRT file. Line breaks per block are shown as \n.

Paste from clipboard

Directly paste lyrics from your clipboard or type them. Automatically determines the format. Separates every line as new lyric lines in the workspace.

Standard LRC

Only provides line-by-line timestamping, but is a widely supported format.

Enhanced LRC

Provides line-by-line and word-by-word timestamping, but support is limited. Players like Namida support this format.

SRT

Only provides line-by-line timestamping. Widely supported video subtitle format.

Region looping mode

When clicked, the selected region in the waveform will continuously loop until this is disabled.

Disable blank new line as line end time

Disables adding a blank new line as a line's end time for standard and enhanced LRC, adding a trailing tag for the latter. Prettier, but compatibility may be limited.

Auto-scroll

Enables auto-scrolling to the active lyric line in the main workspace. Auto-scrolling will pause when typing or scrolling away.
